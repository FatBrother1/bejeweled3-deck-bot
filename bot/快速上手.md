# 快速上手（3 分钟）

## 在 Steam Deck 上（已装好，直接用）

```bash
ssh deck@<你的Deck IP>
cd /home/deck

./run2.sh on        # ★打开：游戏一开就自动跑 bot
./run2.sh off       # ★关闭
./run2.sh status    # 看状态
./run2.sh play 20   # 手动跑 20 步
./run2.sh dry 3     # 只识别不点击（验证识别）
```

**不想用了怎么关**：`./run2.sh off`。
（守护是临时 systemd 单元，**重启机器也会自动消失**，不会背着你跑。）

## 在别的 Linux 机器上

```bash
# ① 装依赖
#   Arch/SteamOS:
sudo pacman -S --needed python-numpy python-evdev python-pillow gstreamer gst-plugin-pipewire xdotool
#   Debian/Ubuntu:
sudo apt install python3-numpy python3-evdev python3-pil gstreamer1.0-tools gstreamer1.0-pipewire xdotool

# ② 解压 + 安装
tar xzf bejeweled3-bot-kit.tar.gz -C ~/bjbot-kit
bash ~/bjbot-kit/install.sh          # 装到家目录
# 或指定目录： bash ~/bjbot-kit/install.sh /home/你的用户名

# ③ 标定（必做！换分辨率必须做）
python3 ~/calib.py                   # 看 overlay 图确认网格对准
# 对准了加 --save 写入

# ④ 验证
cd ~ && ./run2.sh dry 3              # 看"未知格"是否为 0
./run2.sh on
```

## 三个必须注意的点

1. **换机器/换分辨率必须重新标定**（`calib.py`），否则点错格子
2. **抓帧可能要用改**：`capture_pw.py` 里的 `path=93` 是本机 PipeWire 节点号，
   换机器用 `pw-cli ls Node` 找游戏的视频流，改成新编号
3. **别追求更快**：物理上限 1.39 步/秒（动画 535ms + 拖动 182ms 不可压缩），
   超过就是假速度（交换被游戏吃掉）

## 是否必须装高清补丁

不是必须，但**换画质就要重标定**。颜色阈值是按 1280x800 + 汉化高清补丁标定的。
验证方法：`./run2.sh dry 3`，看"未知格"是不是 0。
