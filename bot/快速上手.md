# 快速上手

## Steam Deck

已经装好的话，直接：

```bash
cd /home/deck
./run2.sh on        # 开
./run2.sh off       # 关
./run2.sh status    # 看状态
./run2.sh dry 3     # 只识别不点击，验证识别
```

`on` 是守护模式，游戏一启动它就跟着跑，游戏退了它停。重启 Deck 之后就没了，
不会背着你跑。

## 别的 Linux 机器

先装依赖。Arch 或 SteamOS：

```bash
sudo pacman -S --needed python-numpy python-evdev python-pillow \
    gstreamer gst-plugin-pipewire xdotool
```

Debian 或 Ubuntu：

```bash
sudo apt install python3-numpy python3-evdev python3-pil \
    gstreamer1.0-tools gstreamer1.0-pipewire xdotool
```

然后装：

```bash
tar xzf bejeweled-bot-1.0.0.tar.gz
cd bejeweled-bot-1.0.0
bash install.sh
```

标定，这一步不能跳：

```bash
python3 calib.py
```

会存一张 `calib_overlay.png`，打开看紫点是不是落在每颗宝石正中心，
青色方框是不是框住整个棋盘。

验证：

```bash
./run2.sh dry 3     # 未知格必须是 0
./run2.sh on
```

## 三件要注意的

换机器或者换分辨率必须重新标定，不然会点错格子。

抓帧可能得改。`capture_pw.py` 里那个 `path=93` 是本机的 PipeWire 节点号，
换机器用 `pw-cli ls Node` 找工作机的视频流，改成新编号。

别想着更快。物理上限是每秒 1.39 步，也就是 717 毫秒一步（游戏动画 535 毫秒
加拖动 182 毫秒）。超过这个数就是假速度，交换会被游戏吃掉。

## 高清补丁

不是必须装，但换了画质要重新标定。颜色阈值是按 1280x800 加汉化高清补丁调的。

判断办法：

```bash
./run2.sh dry 3
```

未知格是 0 就没问题。

详细文档看 `README.md`。
