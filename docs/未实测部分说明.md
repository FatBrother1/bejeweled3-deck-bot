## 如何判断你的环境能否用

```bash
cd bot
./run2.sh dry 3      # 只识别不点击
```

看输出的**"未知格"数量**：
- **0 个** ⇒ 环境可用
- 1~3 个 ⇒ 可能有道具特效，勉强能用
- 多于 3 个 ⇒ 标定或颜色阈值不匹配，需要调

如果连 `dry` 都跑不起来（抓帧失败等），说明环境不满足要求，
参考 [`安装与使用.md`](安装与使用.md) 的"其他 Linux 机器"一节。
