# 回滚操作说明

分三层，按「影响面从小到大」排。所有操作都可在 Deck 上直接跑。

## 第一层：只停 bot（不动任何文件）

```bash
cd /home/deck
bash run2.sh off          # 停守护 + 停 bot
bash run2.sh status       # 确认：守护 inactive、bot 未运行
```

`run2.sh off` 内部就是 `pkill`。想只停守护、留着 bot 跑：

```bash
systemctl --user stop bejewel-watch
```

反过来启动一律用 `run2.sh on`（它走 `systemd-run` 起临时单元）。
**不要**从 SSH 里裸 `setsid nohup` 起 bot——会话一断就会被 SIGKILL，
这个坑复现过两次。

## 第二层：回滚 bot 代码

历轮改动前都留了备份：

```bash
ls -d /home/deck/bjbot/backup-*/ /home/deck/backup-*/      # 看有哪些备份
```

按名字找对应那一轮（比如 `backup-cap-20260927` 是抓帧兜底那次改之前的），
把里面的文件拷回去，然后 `run2.sh off && run2.sh on`。

也可以直接从仓库某个 tag 取：

```bash
cd /tmp/bjbot-repo
git fetch --tags
git checkout v0.2.19          # 或任意历史版本
cp bot/*.py /home/deck/       # 注意 bot 代码在 /home/deck/ 下
```

回滚完记得核一遍 md5 与预期一致，再看 `tail -30 /home/deck/bjbot/bot.out`
确认它真的在出招，而不是只看进程在不在。

## 第三层：回滚或卸载插件

包里的 `rollback.sh` 就是干这个的（与仓库 `decky-plugin/BJBot/rollback.sh`、
以及 `输出/2026-09-24/bejeweled/Decky插件/rollback.sh` 三份内容完全一致）：

```bash
bash rollback.sh
```

它做四件事：删掉 `/home/deck/homebrew/plugins/BJBot`、重启 `plugin_loader`、
等 12 秒、然后打印插件数（基线 15）、BJBot 是否还在（应为 0）、loader 是否 active、
可用内存。**这是彻底卸载**，bot 本体不受影响。

只想换回旧版插件（不卸载）：

```bash
# 从某个 Release 下 BJBot-<版本>.zip 解开
unzip BJBot-0.2.19.zip -d /tmp/bjold
sudo -n cp /tmp/bjold/plugin.json /home/deck/homebrew/plugins/BJBot/plugin.json
sudo -n cp /tmp/bjold/package.json /home/deck/homebrew/plugins/BJBot/package.json
# dist/ 与 main.py 等按需覆盖（属主 deck:deck 的直接 cp，root 的用 sudo -n cp）
sudo -n systemctl restart plugin_loader
sleep 10
sudo journalctl -u plugin_loader --since "-3min" | grep BJBot
```

`plugin.json` 是 root:root，所以必须 `sudo -n cp`；`package.json` 是 deck:deck。
`plugin_loader` 是**系统单元**，查日志用 `journalctl -u plugin_loader`，
加 `--user` 什么都查不到。

## 出了事怎么判断

| 现象 | 先看哪里 |
|---|---|
| 侧边栏里没有 BJBot | `sudo journalctl -u plugin_loader --since "-5min" \| grep -i bjbot` |
| 插件在但点了没反应 | `/home/deck/homebrew/logs/BJBot/*.log`（记 `start rc=` / `stop rc=`） |
| bot 不打了 | `tail -50 /home/deck/bjbot/bot.out`，先看抓帧后端和有没有 `抓帧失败` |
| 游戏里画面冻住、拖动全被拒 | 大概率是失焦暂停，看日志有没有 `⏸冻结`；bot 会自己抢焦点/点返回 |
| 完全连不上 Deck | 多半是睡眠断网，等它醒；不要改配置 |

## 兜底原则

这个项目所有改动都是「改文件 + 重启进程」，没有不可逆操作。
真到最坏情况：`rollback.sh` 卸插件、`run2.sh off` 停 bot，
游戏本身一个字节没被改过，随时可以当它不存在。
