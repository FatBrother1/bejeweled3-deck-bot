# 容器工作目录说明

这个项目全部是在手机上的 DSHA 容器里做的（容器 uid=0，Android app 上下文），
Deck 只是被 SSH 过去的远端机器。所以「文件在哪」要分三块看：容器 `/tmp` 里的是
干活时的临时目录，`/sdcard/Download/DSHA/输出/` 是存档，`~/.dsh/workspace/` 是记忆。

## /tmp/bjbot-repo —— 仓库克隆

- 当前 HEAD：`5bab585 fix: which_mode.py 放一份进 bot/`，与 GitHub main 一致
  （上一个提交 `9924d9d` 修的是 install.sh 部署清单）。
- remote 是 `https://FatBrother1:<PAT>@github.com/FatBrother1/bejeweled3-deck-bot.git`，
  token 明文内嵌在 remote URL 里。这是本机为了免交互推送做的便利，别把这份 `.git`
  打包出去。
- 发版、打 `git archive` 资产都在这儿做。
- 性质：临时。`/tmp` 重启即失，要长期留就把改动推回 GitHub。

## 一句话分工

要重跑、要发版，用 `/tmp/bjbot-repo`（没了就重新 clone）。
要给人看的报告和记录材料，写进 `输出/<日期>/bejeweled/`。
要跨会话记住的事实，写进 `~/.dsh/workspace/reference/` 并更新索引与 memory-log。
`/tmp` 里的一切都当作可丢。
