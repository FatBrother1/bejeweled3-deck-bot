# 覆盖 v2.0.0 的发行资产（2026-09-27）

## 起因

用户问「GitHub的发行版有没有这个问题」。答案是**有，而且比仓库里更惨**。

`install.sh` 的修复提交 `9924d9d` 落在 v2.0.0 发布**之后**，而 v2.0.0 的三个资产是
`0e0753a` 那一刻的快照 ⇒ 资产里装的还是旧的 `install.sh`（`482a3b53`）。

## 实拉三个资产核出来的事实

把三个资产从 GitHub 下下来逐个解包、逐个干装（抠出 install.sh 里「② 复制文件」整段
源码 + 补回脚本开头的 `set -e`，目标指向临时目录）：

| 资产 | 文件数 | 里面的 install.sh | which_mode.py | 干装结果 |
|---|---|---|---|---|
| `bejeweled-bot-2.0.0.zip` | 46 | `482a3b53`（旧） | **不在包里**（只有 bot 目录，没有插件目录） | **中断在 `which_mode.py`，退出码 1，只落地 15 个文件、`modes/` 0 个、棋盘 0 份** |
| `bejeweled3-deck-bot-2.0.0.zip` | 90 | `482a3b53`（旧） | 在 `decky-plugin/BJBot/` | 旧脚本同样中断；换成修好的脚本干装 = 退出码 0、38 文件、`modes/` 10、棋盘 5、零警告 |
| `BJBot-2.0.0.zip` | 17 | **没有** | — | **不受影响**（纯插件包） |

**关键在第一个**：它连 `modes/` 都装不上，而 `bot_v6.py` 第一件事就是 `import modes`
⇒ 从 `bejeweled-bot-2.0.0.zip` 装出来的是个**完全跑不起来**的 bot，不是"只有牌局坏"。
旧脚本在 `which_mode.py` 那一步 `set -e` 就退了，后面 `watch2.py`、`run2.sh`、
`modes/*.py`、五份棋盘几何一个都没轮到。

## 决策（用户拍板）

1. **覆盖 v2.0.0 的包**，不发新版本 —— 所以 tag、Release 说明、`plugin.json` 的
   版本号全部**不动**（仍是 2.0.0）；
2. **把 `which_mode.py` 放一份进 `bot/`**，让只有 bot 目录的那个资产也能自足安装。

## 改动

**仓库**（提交 `5bab585`，已推 main）：

- 新增 `bot/which_mode.py`，与 `decky-plugin/BJBot/which_mode.py` **逐字节一致**
  （都是 `5a60be25`）。
  为什么必须这样：`bejeweled-bot-*.zip` 是用 `git archive HEAD:bot` 打的，里面没有
  `decky-plugin/`，所以 `install.sh` 里那条「去插件目录找」的兜底对它无效 —— 上一轮
  的修复能让它不中断，但装完认不出模式（守护退回 `--mode auto`）。`bot/` 下放一份之后，
  查找的第一条路径就能命中。

**发行资产**：从新 HEAD 重新用 `git archive` 打三个包，**删除旧的三个资产、上传新的三个**
（同名同 tag，只换字节）。逐个换、每换一个立刻验证，避免中途失败留下空窗。

## 验证

**线上三个资产与本地构建逐字节一致**（重新从 GitHub 下载后比 sha256）：

| 资产 | 字节 | sha256 前 16 位 | 与本地 |
|---|---|---|---|
| `bejeweled3-deck-bot-2.0.0.zip` | 1523829 | `144b77d4ad3624fe` | ✅ |
| `bejeweled-bot-2.0.0.zip` | 131733 | `7f9fb257b3e139a7` | ✅ |
| `BJBot-2.0.0.zip` | 1320730 | `b52f7a429535ddde` | ✅ |

三个包都过 `testzip()`、无 `__pycache__`。

**从线上 bot 包做完整干装**（就是用户下载后跑 `install.sh` 的真实场景）：

```
退出码: 0
落地 38 个文件   modes/ 10 个   棋盘 5 份
bot_v6.py 在   watch2.py 在   run2.sh 在   which_mode.py 在
poker.py 在   solver_poker.py 在   calib.py 在   solver_fast.py 在
零警告零错误
which_mode.py 里 /home/deck 残留: 0 处（路径改写生效）
```

整仓包解出来 91 个文件，`bot/install.sh` = `f0c6a77d`，`bot/which_mode.py` 与
`decky-plugin/BJBot/which_mode.py` 两份都是 `5a60be25`。

## 影响面

- **Deck 不受影响**：它是历轮手动传的文件，`bot/` 下该有的都在；这次改的只是仓库与
  发行资产。
- **已经下载过旧资产的人**：文件名、tag、版本号都没变，但字节变了 —— 重新下载即可，
  旧的那份装不起来。
- `plugin.json` 仍是 2.0.0 ⇒ **Deck 上的插件不用重装**（而且插件本来就不打包 bot）。
