# 项目一句话说明

BJBot 是「在 Steam Deck 上自动玩 Bejeweled 3（宝石迷阵 3）」的一套东西，分两半：

- **bot 本体**：一套 Python 脚本。棋盘直接从游戏进程的内存里读出来（只读，从不写入），
  每步算一个最优交换，然后用模拟鼠标拖过去。游戏文件一个字节都不改。
- **Decky 插件**：Steam Deck 侧边栏里的一个面板，用来在游戏模式下开关 bot、
  看当前模式/脚本/抓帧后端/步数，不用切到桌面模式开终端。

两半是独立的：插件只负责把 bot 拉起来和显示状态，打牌全在 bot 里。

## 它怎么工作

```
读内存（只读）→ 拿到棋盘 → 算一步 → 模拟鼠标拖动
PipeWire 抓屏 → 只用来判断结算画面、识别模式、看棋盘有没有静止
```

抓屏优先走 PipeWire 的 `Video/Source` 节点（90 帧每秒，节点号启动时自动找），
拿不到就退到 `gamescopectl screenshot` 兜底（两秒一帧，慢但不会瞎），
待在兜底上时每分钟回试一次 PipeWire，节点回来了自己切回去。

棋盘识别有两套后端，默认自动选：**内存**（一次 1.18 毫秒，不会把火焰宝石读成白色、
不依赖画面标定）和**视觉**（截屏识别颜色，最早的做法，现在是后备）。

## 现在的版本

- 插件版本 **v2.0.0**（正式版），bot 代码跟着仓库 main 走。
- 仓库：`https://github.com/FatBrother1/bejeweled3-deck-bot`（public，MIT）。
- 八个游戏模式，一个模式一个文件，默认自动识别。

## 它不做什么

- 不注入游戏进程，不写游戏内存，不改游戏文件。
- 不联网，不上传任何东西。
- 不读游戏里的账号信息。

## 提醒

自动玩可能违反游戏的服务条款，被封号的风险自己承担。

代码全部由 AI 编写（deepseek-v4.1-flash 为主），人一行没写。中间的翻车和
结论被推翻的过程都留在技术报告和踩坑记录里，没有美化。
