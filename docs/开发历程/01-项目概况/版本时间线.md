# 版本时间线

插件版本号只有一个来源：`decky-plugin/BJBot/plugin.json`，GitHub Release 的 tag 与它一致。
已发布版本的资产不覆盖、不 force-push——早期覆盖过一次，结果 tag 指向的提交和它挂的包
不是一回事，已经下载过的人拿到的东西跟仓库对不上。

## 开发轮次与版本的对应

开发是按「轮」走的，一轮解决一个问题，技术报告在 `02-技术报告/` 里按轮存放。

- 第 1~14 轮（09-24 ~ 09-26）：从零跑通 → 内存后端 → 牌局模式 → 插件正规重建 →
  钻石矿 → 特殊宝石建模 → 模式显示修复 → 失焦暂停自愈。
- 第 15~18 轮：蝴蝶优先消蝴蝶 → 通用失焦暂停自愈 → 牌局同花优化 → 模式脚本化。
- 第 19~21 轮：闪电三连修 → 经典攒万变魔方 → 牌局按牌型阶梯重写。
- 第 22~23 轮：抓帧兜底修复 → 正式版 v2.0.0。

轮次细节见 `06-开发进度与存档记录/`。

## 每个 Release 挂三个资产

用 `git archive` 生成，三份内容一致只是范围不同：

- `bejeweled3-deck-bot-<版本>.zip` —— 整个仓库
- `bejeweled-bot-<版本>.zip` —— 只有 `bot/`（bot 本体）
- `BJBot-<版本>.zip` —— 只有 `decky-plugin/BJBot/`（插件）

`git archive` 的好处是自动排除 `.git` 和 `__pycache__`，不用手写排除规则。
